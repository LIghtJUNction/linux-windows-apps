# 兼容性诊断

## 先定位失败层

区分安装器退出、文件已安装、原生窗口启动、WebView 渲染和实际功能完成。收集所选 runner、prefix、退出码、相关日志和真实截图。日志的最后一行不一定是故障原因。无 DISPLAY 时先处理显示连接，不直接归咎应用。

## 中文方框

宿主有中文字库不等于 Wine 内应用会使用它。先看原始导出是否为 UTF-8、字段是否已乱码，再检查 `fc-list :lang=zh` / `fc-scan` 字体是否包含所需字形。只在选定 prefix 安装有授权的中文字体；按 Wine 和软件使用的字体注册及 FontLink fallback 配置，保留原注册表值并备份。重新启动该应用，真实查看中文字段。不要把替换源文献内容当成字体修复，也不要覆盖其他 Bottle 的字体设置。

## WebView2

Microsoft runtime 安装器返回成功、磁盘上存在文件、检测 API 返回版本、浏览器进程成功绘制是四件事。Wine 兼容性可能阻断后两步。仅对已确认存在的 runtime 设置 `WEBVIEW2_BROWSER_EXECUTABLE_FOLDER` 才有意义，不能伪造注册表版本。不要默认关闭浏览器沙箱或 GPU 来宣称修复。原生功能可工作而嵌入网页失败时分别记录。

官方参考：[WebView2 分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。本技能没有保证 WebView2 可运行的补丁。

## 截图黑屏 / 控件缺失

PrintWindow 返回非零仍可能得到黑图。最小化、离屏窗口、GPU 表面和 compositor 重定向均可能影响捕获。优先在私有桌面实际绘制再截屏，不激活用户正在使用的窗口。普通 Win32 helper 不涵盖 UI Automation、Electron DOM、owner-drawn 控件或应用私有数据库。需要其他工具时按当前环境能力选择，不能把静态截图或模拟控件当成真实软件操作。

## 资源缺失

少数程序依赖语言 MUI 资源，Wine 加载行为可能不同。保留原始签名可执行文件；仅在确认具体缺失资源并获软件许可允许的情况下研究副本，不能把修改激活/授权校验包装成兼容性修复。本仓库不提供第三方二进制补丁。

## 回滚

改变 runner、字体、注册表或运行库前，关闭并保存选定 prefix 内应用，备份到用户指定备份根并校验。不要直接降级已经迁移的数据文件；先在独立副本验证。安装和试用操作遵循用户已有授权，遇到购买、额外条款或身份承诺时提供具体内容。
